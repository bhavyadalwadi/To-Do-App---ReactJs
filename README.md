# To-Do-App---ReactJs [Archived]

Status: Archived. Kept as older practice work.

Simple React to-do list app for adding and removing tasks with lightweight animations and icon-based actions.

## Why this repo exists

This repo is a small front-end practice app focused on React component state, list rendering, form handling, and animated item removal.

## What it does

- Adds tasks through a text input and submit flow
- Prevents empty submissions
- Renders tasks as a live list
- Removes tasks with a trash icon action
- Uses transition effects for list updates

## Run locally

1. Install dependencies:
   `npm install`
2. Start the app:
   `npm start`
